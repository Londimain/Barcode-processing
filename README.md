# Списание акцизных марок

## Описание проекта

Веб-приложение для подготовки и обработки данных акцизных марок (Data Matrix, GTIN), предназначенное для упрощения рутинных операций: поиска недостающих марок, сортировки, расчёта диапазонов, работы с БСО, удаления марок и других задач. Приложение работает полностью в браузере (клиентская часть), не требует серверной инфраструктуры и может использоваться локально.

## Возможности

- **Поиск недостающих марок** — сравнение исходного файла (или папки) с папкой вычитаемых файлов. Результат можно скачать.
- **Сортировка GTIN приёмки с БСО** — группировка кодов по GTIN, сортировка по возрастанию, автоматическое сохранение отдельных файлов для каждой группы.
- **Формирование и расчёт диапазона GTIN** — фильтрация марок по указанному диапазону с сортировкой.
- **Калькулятор дней** — расчёт конечной даты срока годности по начальной дате и выбранному сроку (360/180/150 дней).
- **Удаление марок из файла** — удаление последних 13 символов в каждой строке и сохранение файла с суффиксом `-NoMark`.
- **Обработка данных** (страница `obrabotka.html`):
  - Ввод штрихкодов с автоматическим удалением дубликатов.
  - Подсчёт количества отсканированного товара, партий, упаковок.
  - Определение названия продукта по Excel-словарю (или резервному списку).
  - Сохранение результата с добавлением символов GS, проверкой CRLF, удалением `]d2`.
  - Сортировка общего количества товара по базе данных.
  - Разделение файла по количеству кодов.
  - Расширенная обработка файла (удаление дубликатов, вставка GS, CRLF).
  - Обработка двух файлов (вычитание строк).
  - Поиск кодов по базе данных.
  - Звуковые оповещения (включаются чекбоксом).
- **Страница контактов** с возможностью копирования email по клику.
- **Страница настройки сканера** с инструкциями и «замыленными» изображениями (проявляются по клику).
- **Страница инструкции** с интерактивными кнопками и подсказками.
- **Страница описания** всех функций.
- **Адаптивный дизайн** (поддержка мобильных устройств).
- **Тёмная тема** (автоматически при системных настройках).

## Использование

### Страница «Списание» (`cancellation.html`)

- **Поиск недостающих марок**  
  Загрузите исходный файл (или папку с TXT) и папку с вычитаемыми файлами. Нажмите «Поиск марок». Результат отобразится в текстовом поле, его можно скачать.  
  Файлы с дополнительными номерами марок (длиной более 39 символов) обрабатываются: последние 13 символов удаляются для сравнения, но возвращаются в результат.

- **Сортировка GTIN приёмки с БСО**  
  Загрузите файл или папку с TXT. Нажмите «Обработать коды». Коды группируются по GTIN (символы со 2-го по 16-й), сортируются по возрастанию последних 13 символов, для каждой группы автоматически скачивается файл `GTIN (количество).txt`.

- **Формирование и расчёт диапазона GTIN**  
  Укажите начальную и конечную марки (12 символов, одинаковый префикс). Загрузите файл. Нажмите «Формировать» — отфильтрованные и отсортированные марки будут сохранены в файл.

- **Калькулятор дней**  
  Выберите начальную дату и один из сроков годности (360, 180, 150). Нажмите «Рассчитать» — отобразится конечная дата.

- **Удаление марок**  
  Загрузите файл с GTIN и марками. Из каждой строки удаляются последние 13 символов, файл сохраняется с суффиксом `-NoMark`.

### Страница «Обработка данных» (`obrabotka.html`)

- Ввод штрихкодов в текстовое поле (дубликаты удаляются, символы GS удаляются).
- Автоматическое определение названия продукта по Excel-словарю.
- Подсчёт количества товара, партий, упаковок.
- Сохранение результата с проверкой и добавлением GS, CRLF, удалением `]d2`.
- Сортировка общего количества товара по базе данных (папка с TXT) и экспорт в Excel.
- Разделение файла по количеству кодов.
- Расширенная обработка файла (удаление дубликатов, вставка GS, CRLF).
- Обработка двух файлов (вычитание).
- Поиск кодов по базе данных.
- Звуковые оповещения (включаются чекбоксом «Включить звуковое оповещение»).

### Страница «Контакты» (`contacts.html`)

Таблица сотрудников. Клик по email копирует его в буфер обмена.

### Страница «Настройка сканера» (`customization.html`)

Инструкции по настройке сканера IDPRT ST500 / HN-7278HD с изображениями штрихкодов (изначально размыты, проявляются по клику).

### Страница «Инструкция» (`manual.html`)

Интерактивные кнопки, при нажатии на которые появляется краткое описание соответствующей функции.

## Настройка

- **Словарь продуктов** — Excel-файл (`.xlsx`, `.xls`) с двумя столбцами: префикс GTIN и название. Загружается на странице `obrabotka.html`. При отсутствии файла используется резервный список, встроенный в `loadProductMapFromExcel.js`.
- **Звуковые файлы** — размещаются в папке `sounds/`. Форматы `.mp3` и `.ogg`.
- **Изображения** — папка `images/`, включая `favicon-16x16.png`, `favicon-32x32.png` и подпапку `BarcodeScanner/`.
- **Стили** — `css/styles.css`. Поддерживается тёмная тема (автоматически по системным настройкам).

## Примечания

- Все операции выполняются локально в браузере, данные не отправляются на сервер.
- Для работы с файлами и звуками рекомендуется использовать локальный сервер.
- Приложение протестировано в современных браузерах (Chrome, Edge, Firefox).
- Некоторые функции используют автоматическое скачивание файлов — убедитесь, что браузер разрешает множественные загрузки.
- Для корректного отображения символов GS (Group Separator) в файлах используется соответствующая кодировка.
